# Contribution Policy

AI Vision Director is a source-visible employment portfolio and proprietary
project. It is not an open-source community project.

External code contributions and pull requests are not accepted unless the
copyright holder has provided written approval in advance. Please do not copy,
modify, or submit repository code as a proposed contribution; public visibility
does not grant permission to create derivative work.

Reviewers may share the original repository link or discuss the engineering
decisions represented here. Requests for local evaluation, collaboration, or
other use require prior written authorization from the copyright holder.

The complete evaluation and usage boundary is defined in [LICENSE](LICENSE).
